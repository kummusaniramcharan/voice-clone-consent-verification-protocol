2. Root Cause Analysis: Why Human Voices Scored 82%–90% AI

(A) Uninformative Model Test: Partially Active on Artificial Controls

Observation: Testing 10s of zero silence yields Logits [-0.19, 0.13] → P(AI) = 58.1%; 440 Hz pure sine tone yields Logits [-0.39, 0.35] → P(AI) = 67.8%; uniform white noise yields Logits [0.52, -0.49] → P(AI) = 39.5%.
Impact: Because zero silence sits at 58% AI, evaluating silent pauses in speech artificially dragged scores toward AI. (Energy VAD is strictly required to skip non-speech frames).

(B) Label Swap Test: Verified No Index Inversion

Observation: The model configuration formally maps 0 → "real" and 1 → "fake". Clear clean human speech (e.g. WA0013, WA0014, WA0016, WA0017) outputs negative fake logits with raw scores around 11%–17% AI. The labels are not swapped.

(C) Preprocessing & Normalization: Zero-Mean Unit-Variance + Padding Drop

Observation: Wav2Vec2 audio feature extraction requires exact zero-mean and unit-variance normalization per 4.0-second slice. Additionally, lossy MP3/Opus encoders add ~0.05s–0.2s of encoder priming silence/delay that must be dropped. Failing to normalize each window shifts activations into out-of-distribution states.

(D) Codec/Noise Sensitivity: The Primary Trigger for False Positives

Root Cause 1: The user's WhatsApp clips (WA0015 and WA0018) contain heavy room acoustic reflections, microphone proximity clipping (≥ 0.98 peak), and low-bitrate compression artifacts. The pretrained ASVspoof model (trained only on clean studio speech) misinterpreted these distortion artifacts as synthetic spoofing cues, driving raw single-window logits into 60%–74% AI.
Root Cause 2 (AI domain mismatch): The AI clips (eSpeak 12 voices) were generated using old formant synthesis (vocal tract resonance modeling), which lacks neural vocoder artifacts. Consequently, the ASVspoof model classified eSpeak as only 24%–39% AI!

(E) Aggregation Bug: Peak vs. Median Across Windows

Critical Bug: In earlier builds, the aggregation logic took the maximum (peak) window score instead of the median of speech windows. If a single noisy pause or clipped frame produced an 86% AI spike, the entire 15-second human recording was labeled as "86% AI". Switching to median of speech-only windows immediately resolves this anomaly.

(F) Fallback Heuristic Discrepancy: Complete Removal Required

Observation: Hard-coded heuristic rules (such as adding arbitrary probability for silence or high-frequency cutoff) violate genuine machine learning principles. Any synthetic scoring adjustments must be eliminated; all classification must proceed via pure frozen representations and a calibrated linear classification head.
